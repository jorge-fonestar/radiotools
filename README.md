# 📡 RadioTools

Suite de herramientas web para radioaficionados. Monitoreo solar en tiempo real, cálculo de propagación HF y visualizador interactivo del espectro radioeléctrico.

## Qué hace

- **📡 Monitor Solar**: Condiciones solares en tiempo real (SFI, K/A-Index, manchas solares, rayos X, viento solar) y estado de propagación por bandas HF/VHF
- **📻 Calculador de Propagación**: Predice rutas y bandas óptimas para DX desde tu QTH con cálculo de MUF/LUF
- **🌈 Visualizador de Espectro**: Explorador interactivo del espectro radioeléctrico desde 3 Hz hasta luz visible
- **🌊 Decodificador Waterfall**: Convierte imágenes de waterfall SDR a audio WAV mediante demodulación por centro de masa

## Tecnología

PHP vanilla + HTML/CSS/JS. Sin dependencias. Usa datos de HamQSL.com.

## Instalación

Sube los archivos `.php` y `.css` a tu servidor web. Requiere PHP 7.0+ con cURL. No necesita base de datos.
